### What is TypeScript?

Typescript is a statically typed superset of JavaScript developed but Microsoft. It adds features such as
 - static typing
 - interfaces
 - generic
 - enums
 - access modifiers
 - utility types
and advanced type-system capabilities on top of JavaScript.

**Typescript code is compiled/transpiled into JavaScript, which can then run in browser or NodeJs environment.**

Basic Example
```javascript
const name: string = "Mr Dean";
const age: number = 25;


function addTwoNumber(a: number, b: number) {
	return a + b;
}
```
